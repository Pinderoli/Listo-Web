# Listo-Web

Web version of Listo. This repo is a fresh scaffold — most of the app still
needs to be built.

## Status

Early scaffold only: a static "Hello World" landing page to confirm GitHub
Pages is wired up. No app logic, framework, or build step yet.

## Stack

Not decided yet. Currently plain static HTML/CSS (no build tooling) so the
repo can be deployed via GitHub Pages immediately. Update this section once
a framework/build step is chosen.

## Structure

- `index.html` — landing page, currently a placeholder.
- `README.md` — human-facing project overview.

## Working in this repo

- Keep changes small and commit with clear messages.
- If a build step or framework is introduced later, document the dev/build/
  deploy commands here so future sessions don't have to rediscover them.
